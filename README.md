### 2. 原神角色配置表检查工具
**文件**： 
- `check_character_data.py` （核心脚本）
- `check_report.xlsx` （示例输出报告）

用Python + openpyxl编写的自动化检查工具，基于数值规则自动化检测配表异常。

**检查规则**：
- 角色ID重复检测
- 基础生命/攻击/防御数值范围检查
- 空值检测
- 星级合法性检查（仅允许4、5星）

**运行方式**：将`角色基础属性.xlsx`与脚本放在同一目录，执行 `check_character_data.py`，自动生成`check_report.xlsx`。

---
### 3.  版本差异对比工具
- `weapon_diff.py` （核心脚本）
- `diff_weapon.xlsx` （示例输出报告）
